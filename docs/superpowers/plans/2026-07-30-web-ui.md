# Local Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a secure local Vue 3 chat UI started by `cdy-agent web --workspace .` while preserving the existing Agent loop, confirmation, cancellation, persistence, and CLI contracts.

**Architecture:** A Typer command starts one FastAPI/Uvicorn process bound to `127.0.0.1` and serves committed Vue assets. HTTP handles authenticated bootstrap and saved sessions; one authenticated WebSocket carries turns, deltas, concise tool states, confirmations, and cancellation through a framework-neutral coordinator that reuses the existing Agent and stores.

**Tech Stack:** Python 3.10+, Typer, FastAPI, Uvicorn, Pydantic 2, OpenAI Python SDK, pytest, Vue 3, TypeScript, Vite, Vitest, Vue Test Utils, markdown-it, DOMPurify.

## Global Constraints

- Keep `ask` stateless and preserve current `chat`, tool, Skill, trace, memory, configuration, and error behavior.
- Bind only to `127.0.0.1`; expose `--port` with default `8000`, but no `--host`.
- Resolve one workspace at startup. The browser must never submit or switch the workspace root.
- Permit one active Agent turn for the process. Reject another turn and conversation deletion with `server_busy`; do not queue work.
- Web turns always use provider streaming and the same `Agent.max_model_calls` guard for both `responses` and `chat_completions`.
- A disconnect, refresh, page close, Stop action, or shutdown must cancel the model stream, confirmation wait, and cancellable child process before releasing the active-turn lock.
- Cancellation does not roll back completed side effects, but failed and cancelled turns never enter SQLite or later model context.
- Preserve exact prepared Shell argv, `shell=False`, sanitized environments, bounded output, timeouts, process-tree cleanup, and exact persistent approvals.
- Never send or record API keys, environment dumps, prompts, replies, tool arguments/results, confirmation descriptions, access capabilities, or cookies in logs or traces.
- Keep all Python tests offline and deterministic; mock SDK, process, browser transport, clock, and filesystem boundaries.
- Use `uv` for Python dependency and test commands. Use the committed npm lockfile for frontend commands.
- Commit production Web assets inside `src/cdy_agent/web/static/`; do not package source maps.
- Preserve unrelated tracked and untracked user changes, including the existing untracked planning files.
- Follow test-driven development in every task: observe the focused test fail before adding production behavior.

- [ ] **Step 3: Implement the thread-safe cancellation primitive**

Use `threading.Event` for visibility and a lock-protected callback dictionary. Copy callbacks under the lock, clear the registry, then invoke outside the lock so callbacks can unregister or cancel safely.

```python
class AgentRunCancelled(RuntimeError):
    """Raised when a caller cooperatively cancels an Agent run."""


class RunControl:
    def __init__(self) -> None:
        self._event = threading.Event()
        self._lock = threading.Lock()
        self._callbacks: dict[object, Callable[[], None]] = {}

    @property
    def cancelled(self) -> bool:
        return self._event.is_set()

    def cancel(self) -> None:
        with self._lock:
            if self._event.is_set():
                return
            self._event.set()
            callbacks = tuple(self._callbacks.values())
            self._callbacks.clear()
        for callback in callbacks:
            self._invoke_callback(callback)

    def raise_if_cancelled(self) -> None:
        if self.cancelled:
            raise AgentRunCancelled("Agent run was cancelled.")

    def add_cancel_callback(
        self, callback: Callable[[], None]
    ) -> Callable[[], None]:
        key = object()
        with self._lock:
            if self._event.is_set():
                run_now = True
            else:
                self._callbacks[key] = callback
                run_now = False
        if run_now:
            self._invoke_callback(callback)

        def unregister() -> None:
            with self._lock:
                self._callbacks.pop(key, None)

        return unregister

    @staticmethod
    def _invoke_callback(callback: Callable[[], None]) -> None:
        try:
            callback()
        except Exception:
            pass
```

    stream: object,
    run_control: RunControl | None,
) -> Iterator[object]:

        run_control.add_cancel_callback(close)

        while True:
            if run_control is not None:
                run_control.raise_if_cancelled()
            try:
                event = next(iterator)
            except StopIteration:
                return
            except BaseException:
                if run_control is not None:
                    run_control.raise_if_cancelled()
                raise
            yield event
    finally:
        unregister()

- [ ] **Step 3: Add cancellation registration around `Popen`**

After assigning the Windows Job Object, register a callback that terminates the

```python
def _wait_for_process(
    process: subprocess.Popen[bytes],
    argv: Sequence[str],
    timeout: int,
    deadline: float,
    run_control: RunControl | None,
) -> None:
    while process.poll() is None:
        if run_control is not None:
            run_control.raise_if_cancelled()
        remaining = deadline - time.monotonic()
        if remaining <= 0:
            raise subprocess.TimeoutExpired(list(argv), timeout)
        try:
            process.wait(timeout=min(remaining, 0.05))
        except subprocess.TimeoutExpired:
            continue
```

On every `BaseException`, retain the current ordered cleanup sequence. After
cleanup, call `run_control.raise_if_cancelled()` so cancellation is reported
instead of an incidental pipe or process error.

- [ ] **Step 4: Implement the active-turn state machine**

Use an `asyncio.Lock` only to protect coordinator state, not across worker

```python
class TurnCoordinator:
    def __init__(self, dependencies: TurnDependencies) -> None:
        self._dependencies = dependencies
        self._active: ActiveTurn | None = None
        self._state_lock = asyncio.Lock()

    @property
    def busy(self) -> bool:
        return self._active is not None

    async def start(self, request: TurnStart) -> ActiveTurn:
        async with self._state_lock:
            if self._active is not None:
                raise ServerBusyError("Another turn is already running.")
            turn = ActiveTurn.create(request, self._dependencies)
            self._active = turn
            turn.start(self._clear_when_stopped)
            return turn
```

`TurnCoordinator.__init__` calls `broker.attach(self)` exactly once and refuses
reattachment. The worker builds in-memory history, starts a
`TraceRecorder(command="chat")`,
calls `Agent.run_stream`, persists the complete pair, then emits completion.
Every exception finishes or invalidates tracing best-effort and emits one safe
terminal event. Clear the coordinator only after worker termination.
